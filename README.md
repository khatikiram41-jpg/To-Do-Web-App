📋 Task Management Tool

A responsive and interactive Task Management Tool developed using HTML, CSS, and JavaScript. This project is designed to help users easily create, organize, update, and manage their daily tasks from a simple and user-friendly interface.

🚀 About the Project

The Task Management Tool allows users to add new tasks along with their category, date, and time. Users can organize their tasks into different lists such as Personal, Work, Study, and Shopping, making it easier to manage different types of activities.

The application also provides options to edit, update, complete, search, filter, and delete tasks. Completed tasks are visually distinguished from pending tasks, allowing users to quickly understand their progress.

To improve the user experience, the application includes a Dark Mode/Light Mode feature and a responsive layout that works smoothly across desktop, tablet, and mobile devices.

✨ Features

- ➕ Add new tasks
- ✏️ Edit and update tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- ⏳ Manage pending tasks
- 📅 Set date and time for tasks
- 📋 Organize tasks into different categories
- 🔍 Search tasks quickly
- 🎯 Filter tasks by status and category
- 🌙 Dark Mode / Light Mode
- 💾 Save tasks using Browser Local Storage
- 📱 Fully responsive design
- 🎨 Clean and user-friendly interface
- ⚡ Interactive buttons and controls

🛠️ Technologies Used

- HTML5 – Used to create the structure of the application.
- CSS3 – Used for styling, responsive design, animations, hover effects, and dark mode.
- JavaScript – Used to implement task management functionality, event handling, filtering, editing, deleting, and completion tracking.
- Local Storage – Used to store tasks in the browser so that task data remains available after refreshing the page.
